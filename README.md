# evo-content-search

## 概要

MODX Evolution用のコンテンツ検索スニペットです。コンテンツ検索に適したインデックスを作成し、キーワード検索を行うことができます。管理者が初めて検索ページを開いたときにインデックスの作成とプラグインの登録を行い、以降は管理画面で記事を保存・公開するたびに、その記事のインデックスを自動で更新します。

## 特長

- インデックスの作成による高速な検索
- `[*content*]` の内容をパースした結果を検索対象にすることができます
- タイトル・ディスクリプション・本文のどこに含まれるかと、記事の新しさを考慮した関連度順の並び
- テーマの変更によるカスタマイズ
- セキュリティを考慮した設計

## 動作環境

- evolution-jp 1.3 以上（本体の補助関数を使います。古い版では検索フォームの代わりに案内が表示されます）

## インストール手順

1. **ファイルの配置**  
   `ContentSearch` フォルダ内のファイルを `assets/snippets/ContentSearch/` に配置します。
2. **スニペットの作成**  
   管理画面の「スニペット新規作成」に以下を貼り付けます。

   ```php
   return include MODX_BASE_PATH . 'assets/snippets/ContentSearch/bootstrap.php';
   ```
3. **テンプレートへの設置**  
   テンプレートまたはリソースの適当な場所にスニペットコールを配置します。

   ```html
   [[ContentSearch]]
   ```
4. **初回アクセスでのインデックス作成**  
   管理者でログインした状態で、検索フォームを置いたページを一度開いてください。検索用テーブルとプラグインが自動作成され、サイトのコンテンツを取得してインデックスを生成します（訪問者のアクセスではインデックスを作りません）。

## 使い方

- スニペットコールを配置すると、そこに検索フォームが表示されます。
- 初回（管理者が検索ページを開いたとき）は検索インデックスの作成が行われるため、少し時間がかかります。
- 非公開・削除済み・会員限定（`privateweb`）・検索対象外の記事は、検索結果に出ません。記事の状態を変えると、次の検索からすぐに反映されます。
- キーワードを入力して検索ボタンを押すと、検索結果が表示されます。
- 管理者でログインしているとフォームに「インデックスを再構築する」リンクが表示され、インデックスを再作成できます。リンクには管理者のセッションに結びついたトークンが付き、トークンのない `?reset=1` だけでは再作成されません。

## スニペットパラメータ

`themes/_default/config.php` の値をベースに、スニペット呼び出し時のパラメータで上書きできます。主なパラメータは以下の通りです。

| パラメータ | 役割 | デフォルト |
| --- | --- | --- |
| `theme` | 使用するテーマ名。`themes/<theme>/config.php` が読み込まれます。 | `_default` |
| `limit` | 1ページあたりの表示件数。URL の `limit` で変えられるのは 100 件まで（この値が 100 より大きければこの値まで）。 | `10` |
| `mode` | 検索モード（`like`/`auto`/`fulltext`）。下の「検索モードの挙動」を参照。 | `like` |
| `minChars` | 最低入力文字数。未指定時はチェックなし。 | なし |
| `keyword` | キーワードを受け取るクエリパラメータ名。 | `keyword` |
| `basicAuth` | インデックス作成時に使用する Basic 認証情報（`user:pass`）。未指定なら、管理者がアクセスしているときの認証情報を使います（サイト全体に Basic 認証をかけている場合は通常不要）。指定した値は、記事保存時の索引更新でも使うため、システム設定 `cs_index_options` に保存されます。 | なし |
| `returnResponse` | スニペットの戻り値を出力するかどうか。 | `true` |
| `placeholder-key` | プレースホルダーにセットするキー名。 | `ContentSearch` |
| `additionalKeywordField` | 追加でキーワード化するフィールド名。 | 空文字 |
| `paginateAlwaysShow` | 1ページしかなくてもページネーションを表示するか。 | `false` |
| `css` | インラインで読み込むスタイル。テーマの `template/style.css` が既定。 | テーマ依存 |

## テーマとテンプレートのカスタマイズ

- テーマは `ContentSearch/themes/<theme>/` 配下に配置します。`config.php` で各テンプレートやスタイルを定義します。
- `_default` テーマは以下のテンプレートを持ちます。必要に応じてコピーして編集してください。
  - `template/form.html`：検索フォーム。キーワード入力欄の `name` には `[+keyword-param+]`（`keyword` パラメータの値）を使います
  - `template/result.html`：検索結果 1 件分の表示
  - `template/admin-widget.html`：管理者向けの再インデックス用ウィジェット
  - `template/style.css`：フォームと結果一覧のスタイル
- 検索結果のラッピングやページネーションは `tplResults` / `tplPaginate` セクションで HTML を差し替えできます。

## 検索モードの挙動

- `like` モード（既定）: プレーンテキストから部分一致で検索します。日本語でも結果が予測しやすく、2文字の語も検索できます。数千ページ程度までのサイトなら速度も問題ありません。
- `fulltext` モード: MySQL/MariaDB の全文検索で候補を絞り、部分一致で確かめます。ページ数がとても多いサイト向けです。InnoDB の標準パーサーは日本語を正しく区切れないため、見つからない場合は `like` に切り替えて探し直します。
- `auto` モード: `innodb_ft_min_token_size` の値を参照し、キーワードの語のどれか1つでもそれより短ければ（「本文」「検索」などの2文字の語）`like`、それ以外は `fulltext` を使用します。

## 関連度順の並び方

関連度順（既定）では、検索語ごとに次の点数を足し合わせ、新しい記事を少し優遇します。どちらのモードでも同じ計算です。

- タイトルに含む: +10
- ディスクリプションに含む: +4
- 本文の冒頭 300 文字に含む: +2
- 出現回数 × 0.5（10 回まで）
- キーワード全体がタイトルと一致: +10（タイトルの先頭と一致: +5）
- 公開直後の記事は 1.5 倍。90 日ほどでボーナスが半分程度になります

## インデックスとメンテナンス

- 管理画面で記事を保存・公開すると、プラグインがその記事のインデックスを自動で更新します。
- 公開前（予約公開を含む）の記事は、保存した時点で本文をそのまま（スニペットの結果を含まずに）インデックスに入れ、公開されると検索結果に出ます。
- 一括操作などでプラグインを通らずに更新された記事は、管理者が検索ページを開いたときに取り込まれます。訪問者のアクセスではページの取得を行いません。
- 「インデックスを再構築する」リンク（`reset` とトークン付き）から、テーブルの再作成と再クロールを行えます（管理者のみ）。独自テーマの `admin-widget.html` は、リンクに `&amp;token=[+token+]` を付けてください。
- 再インデックス後はキャッシュがクリアされ、最新の情報が検索に反映されます。

## 以前の版から更新する場合

ファイルを置き換えたあと、管理者でログインして検索ページを一度開いてください。プラグインが新しい内容に自動で更新されます。続けて「インデックスを再構築する」リンクから再構築しておくと確実です。

主な変更点と、必要な対応は次のとおりです。

- **動作環境が evolution-jp 1.3 以上になりました。** それより古い版では、検索フォームの代わりに案内が表示されます。
- **既定の検索モードが `like` になりました。** これまでの `auto` を使い続けたい場合は、スニペット呼び出しに `&mode=auto` を付けてください。
- **インデックスの更新は、記事の保存・公開のときに行うようになりました。** 訪問者のアクセスでは行いません。
- **独自テーマを使っている場合**
  - `admin-widget.html`: 再構築リンクに `&amp;token=[+token+]` を付けてください（付けないと再構築できません）。
  - `form.html`: `keyword` パラメータを既定から変えた場合は、入力欄の `name` を `[+keyword-param+]` にしてください。
- **プレースホルダーの既定のキー名を `ContentSearch` に直しました**（以前は綴り間違いの `ContentSeach`）。互換のため旧名にも同じ値が入るので、既存のテンプレートはそのまま動きます。

## 開発のヒント

- スニペット本体は `ContentSearch/bootstrap.php` です。処理は `ContentSearch/core/` にあります。
  - `EvoContentSearch.php`: 設定の読み込み、入力値の整え、全体の流れ
  - `SearchQuery.class.php`: 検索と件数の SQL、関連度の計算
  - `Paginator.class.php`: ページ送り
  - `Summary.class.php`: 要約とハイライト
  - `save-index.class.php`: インデックスの作成・更新、プラグインの登録
  - `plugin-code.php`: プラグインのコード（インデックス作成時に DB に登録されます）
- テーマの既定設定は `ContentSearch/themes/_default/config.php` で確認できます。開発時はここを基準に追加パラメータを定義すると、ドキュメントと実装の乖離を防げます。
